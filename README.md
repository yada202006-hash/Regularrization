Regularization is a technique used to prevent overfitting in machine learning models by adding a penalty term to the loss function.
This repository demonstrates three popular regularization methods:
**Ridge Regression (L2 penalty)** – shrinks coefficients but keeps all features.
**Lasso Regression (L1 penalty)** – performs feature selection by driving some coefficients to zero.
**Elastic Net (L1 + L2 penalty)** – combines Ridge and Lasso, useful when features are correlated.
